# React Fundamentals Practice

A beginner-friendly React project built with React and Vite.

## Features

- Responsive navigation bar
- Dashboard and Widgets navigation links
- Interactive Apps dropdown menu
- React `useState` for dropdown state management

## Technologies

- React
- JavaScript (ES6+)
- CSS3
- Vite
- HTML5

## Run Locally

```bash
npm install
npm run dev
```

Open the local URL displayed in your terminal.

## Production Build

```bash
npm run build
```

## Learning Goals

- Understand React components
- Practice JSX
- Learn React state with `useState`
- Organize a React project
- Build and test a React application
